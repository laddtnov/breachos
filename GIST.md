# Breachos

A cyberpunk-themed memory card matching game built with vanilla HTML, CSS, and JavaScript. Match pairs of sci-fi operatives, earn XP, unlock ranks, collect card skins, and climb the achievement ladder.

**[Live Demo →](https://breachos.laddtnov.xyz/)**

![Breachos Screenshot](screenshots/03-gameplay.png)

## Game Modes

- **Classic** — Standard rules, limited moves, no timer (except Extreme)
- **Blitz** — Race the clock! Countdown timer, no move limits
- **Survival** — Endless escalating waves with 3 lives
- **Daily Challenge** — Seeded daily puzzle, same for everyone

## Features

- 4 Difficulty Levels (Easy to Extreme)
- 18 Cyber Operatives to match
- 5 Ranks to unlock (ROOKIE → NETRUNNER ELITE)
- 7 Card Skins (Default, Hologram, Corrupted, Gold, Elite, Survivor, Chrono)
- 11 Achievements
- Procedural Web Audio sound effects
- PWA — works offline
- Mobile-first responsive design

## Tech Stack

- HTML5 (PWA manifest, semantic markup)
- CSS3 (3D transforms, animations, Grid, backdrop-filter)
- JavaScript ES6+ (Web Audio API, localStorage, Service Worker)
- **Zero dependencies** — no frameworks, no bundler
